# Hexa Business Website

A responsive, static homepage redesign for Hexa Business, including a muted, optimized hero background video and its still poster.

## Preview locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript; no build step is required.

## Deploy

This repository is configured for static hosting on Vercel. Deploy the project root with no build command and `.` as the output directory.

The contact form opens a prefilled email in the visitor’s mail application. The newsletter form is a front-end placeholder and is not connected to a mailing list.
